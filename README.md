# qa_python

Проект содержит автотесты для класса `BooksCollector` — приложения для управления коллекцией книг.

## Тестируемый класс

`BooksCollector` позволяет добавлять книги, назначать им жанры, формировать список избранного и получать книги, подходящие для детей.

## Реализованные тесты

### `add_new_book` — добавление новой книги
- Книга с валидным названием (1–40 символов) успешно добавляется в коллекцию с пустым жанром
- Книга с невалидным названием (0 или более 40 символов) не добавляется
- Повторное добавление книги с тем же названием не создаёт дубликат

### `set_book_genre` — установка жанра книги
- Книге из коллекции присваивается жанр из допустимого списка
- Книге не присваивается жанр, которого нет в допустимом списке
- Несуществующей книге жанр не присваивается

### `get_book_genre` — получение жанра книги
- Возвращается жанр существующей книги
- Для несуществующей книги возвращается `None`

### `get_books_with_specific_genre` — получение книг по жанру
- Возвращается список книг с указанным жанром
- Возвращается пустой список, если книг с таким жанром нет
- Возвращается пустой список, если коллекция пуста

### `get_books_for_children` — книги для детей
- Возвращаются только книги с жанрами без возрастного ограничения
- Книги с жанрами «Ужасы» и «Детективы» в список не попадают

### `get_books_genre` — получение словаря всех книг
- Возвращается актуальный словарь книг с их жанрами
- Для пустой коллекции возвращается пустой словарь

### `add_book_in_favorites` — добавление в избранное
- Существующая книга успешно добавляется в избранное
- Несуществующая книга не добавляется в избранное
- Повторное добавление книги не создаёт дубликат в избранном

### `delete_book_from_favorites` — удаление из избранного
- Существующая книга успешно удаляется из избранного
- Попытка удалить книгу, которой нет в избранном, не влияет на список

### `get_list_of_favorites_books` — получение списка избранного
- Возвращается актуальный список избранных книг

## Запуск тестов

```bash
pytest test_tests.py
```
